# Bibliothèque audio

Ces fichiers ne sont **pas versionnés** : la licence Mixkit autorise l'usage
commercial sans attribution, mais interdit la redistribution des fichiers.

Lance `python scripts/doctor.py` : il liste les fichiers manquants avec leur titre
exact et le lien de la catégorie Mixkit. Télécharge-les depuis ton compte et
dépose-les ici sous le nom indiqué dans `config/audio_manifest.json`.

Le téléchargement officiel est aussi ce qui enregistre la licence et débloque la
clearance Content ID chez Meta.
